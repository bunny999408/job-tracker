# Job Application Tracker

Live demo: https://job-tracker-z4ux.onrender.com

A web app to track job applications, interview rounds, and follow-ups.

## Features
- User registration and login with hashed passwords
- Add, edit, and delete job applications
- Each user sees only their own data
- Status summary, search, and filters
- Follow-up reminders
- Mobile-friendly design

## Tech
Python, Flask, SQLAlchemy, PostgreSQL (Neon), HTML, CSS. Deployed on Render.
